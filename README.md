# Fiscal Pulse

Agenda contábil para pequenos negócios acompanharem obrigações, prazos e solicitações de documentos em uma visão simples para celular.

## Destaques técnicos

- React Native + Expo + TypeScript
- ASP.NET Core .NET 10, EF Core e PostgreSQL
- Atualização de status e visão consolidada de vencimentos
- Testes de integração, OpenAPI, Docker e CI

## Executar a API

```bash
dotnet run --project api/src
```

Ou use `docker compose up --build`.

> Demonstração independente, com empresa e documentos fictícios. Não é um produto oficial da Constanzo.
